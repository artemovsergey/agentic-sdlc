# Agentic SDLC — личный курс

Курс для разработчика, который работает в **BB** с агентом **OpenCode** на провайдере **OpenCode Go** с моделью **DeepSeek** и хочет перейти от отдельных удачных сессий к повторяемому процессу: ставить задачу, собирать контекст, замыкать проверки, проводить ревью и доводить изменение до релиза. Материал собран по мотивам публичного курса «AI Coding для Разрабов» и roadmap Agentic SDLC, но переработан под ежедневную работу в CollegeLMS: .NET 10, Next.js 14, PostgreSQL и агент OpenCode.

Основная связка курса: **BB → OpenCode → OpenCode Go → DeepSeek**. BB ведёт проект, тред, окружение и worktree; OpenCode крутит цикл «модель → инструменты → результат»; OpenCode Go даёт доступ к моделям; DeepSeek — рабочая модель. Claude Code и Codex упоминаются только как альтернативные harness и не являются вторым путём прохождения.

Это не курс «выучить инструмент». Инструмент уже выбран. Курс про то, как устроить вокруг него процесс, который не разваливается на второй неделе.

## Как проходить

Восемь недель по 4–5 часов. Дедлайнов нет: неделя считается пройденной, когда заполнен `results.md` и есть артефакт, а не когда наступила пятница. Каждая неделя — один-два навыка из маршрута и одна практика на реальной задаче CollegeLMS. Если навык уже освоен, неделя проходится сокращённо: самодиагностика в первую неделю показывает, что можно пропустить, а что закрывать всерьёз.

Правило курса: не читать всё подряд. Конспект задаёт минимум теории, практика проверяет его на задаче, самопроверка показывает пробелы. Если ответ на вопрос самопроверки не находится — возвращайтесь к разделу конспекта, а не к следующей неделе.

## Структура репозитория

- `course/roadmap.md` — 17 навыков Agentic SDLC с критериями «умею» и статусами. Это главный документ прогресса.
- `course/sources.md` — источники, версии инструментов и дата актуальности.
- `course/week-NN/` — материалы недели: `README.md`, `lecture.md`, `practice.md`, `self-check.md`, `results.md`.
- `course/_template/` — шаблон недели, по которому собираются следующие.
- `docs/specs/2026-11-10-agentic-sdlc-course-design.md` — дизайн курса: цели, границы, решения.
- `docs/superpowers/plans/` — планы итераций сборки.

## Порядок недели

1. `README.md` — цель, навыки, чек-лист и артефакт недели.
2. `lecture.md` — конспект на 1200–1800 слов: зачем навык, термины, как это работает в BB и OpenCode, разобранный пример, типичные ошибки.
3. `practice.md` — 4–6 шагов на реальной задаче с проверяемым результатом.
4. `self-check.md` — 5–7 вопросов с ответами.
5. `results.md` — журнал: что сделано, какой артефакт получен, что узнал, что дальше.

`results.md` заполняется по ходу практики, а не после. Это единственный источник доказательств для `roadmap.md`.

## Практика в CollegeLMS

Все практики идут в CollegeLMS и только в отдельном worktree. Прод-каталог `/home/user1/CollegeLMS` не трогаем: там живут контейнеры, и любая ошибка видна пользователям.

Перед первым изменением создаётся ветка `feat/*` или `fix/*`. Порядок работы: изменение → проверки → коммит → merge в `master` → push. Push запускает CI/CD и пересборку контейнеров, поэтому сначала зелёные проверки, потом push.

Разрешены только низкорисковые задачи: код, тесты, документация, конфигурация приложения. Отдельно согласуются миграции БД, изменения `.env`, `docker-compose.yml` и GitHub Actions. В учебной практике они не выполняются: если задача требует миграции, она откладывается до отдельного согласования.

Команды проверки берутся только из `AGENTS.md` CollegeLMS: `dotnet build CollegeLMS.slnx`, таргетные тесты, `dotnet csharpier check .`, `cd CollegeLMS.Next && npm run build`, `npm run check:design-system`, `npx playwright test {spec}`. В материалах курса команды не переписываются «по памяти»: расхождение с `AGENTS.md` считается ошибкой курса.

## Итерационная сборка

Курс собирается итерациями, а не целиком. В итерации 1 готовы недели 1–2: окружение, постановка задачи, контекст и feedback loop. Недели 3–8 пишутся после того, как пройдены первые две: их содержание зависит от того, какие пробелы в `AGENTS.md` и навыках обнаружились на практике. Так материал не превращается в фантазию о том, как «должно быть».

Статус итерации: недели 1–2 готовы, 2026-11-10. Недели 3–8 — после результатов недель 1–2. План итерации: `docs/superpowers/plans/2026-11-10-agentic-sdlc-iteration-1.md`.

## Как отмечать навык

В `roadmap.md` статус `умею` ставится только с доказательством: ссылкой на артефакт (файл, коммит, запись в `results.md`) или на конкретный результат практики. «Прочитал конспект» доказательством не считается. Статус `в работе` ставится, когда навык применялся хотя бы один раз, но результат ещё нестабилен. Начальный статус — `не начат`.

Честная отметка важнее красивой: курс нужен для себя, а не для отчёта. Если навык не получается, это сигнал вернуться к нему, а не повод поставить галочку.

## С чего начать

Откройте `course/roadmap.md`, проведите самодиагностику по навыкам 1–2 и переходите к `course/week-01/README.md`. Дизайн курса и принятые решения — в `docs/specs/2026-11-10-agentic-sdlc-course-design.md`.
